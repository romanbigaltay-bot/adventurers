# Герои и орки

Пошаговая тактическая артиллерия: играйте вдвоём за одним компьютером или сразитесь с ИИ. Выбирайте состав отрядов и арену, рассчитывайте траекторию выстрела и используйте разрушаемый ландшафт.

## Запуск локально

Требуется Node.js.

```bash
npm ci
npm run dev
```

Откройте адрес, указанный Vite в терминале (по умолчанию `http://localhost:3000`).

## Проверки и сборка

```bash
npm run lint
npm run build
```

Готовая production-сборка появится в `dist/`. Каталог `dist/` и зависимости `node_modules/` не нужно добавлять в Git: они исключены в `.gitignore`.
